Development Environments

The tools we use for coding are collectively called our "development environment." Often just setting up an environment is a complex and time consuming task. Fortunately, all of the tools we need for the basic python coding we will be doing in this course are available through online IDEs or Integrated Development Environments. While students are free to choose their own IDE or even set up their own, we will initially be using Tynker. Open the link below in a new tab and follow either the video or written instructuions.

Tynker

Step by Step

  2. Select Student from the list of Options
  3. Click the "log in with google" option and use your school email.
While IDEs like tynker generally hide individual components of the environment, it is a good idea to have somefoundational knowledge about these parts.

The Text Editor

The text editor is the part of the programming environment that you type text into. You've likely used a text editor before even if you've never done any coding. There are many popular text editors that allow for plugins that make coding easier like VS Code, VIM, and EMACS, but any text editor is capable of being used for programming even notepad or TextEdit.
